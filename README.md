# Bet Analytics

Aplicación web local para analizar los últimos 10 partidos de dos equipos.

## Uso
1. Abrí `index.html` en un navegador.
2. Escribí los nombres de los equipos.
3. Cargá 10 resultados por equipo con formato `GF-GC`, por ejemplo `2-1`.
4. Presioná **Analizar partido**.
5. La app calcula promedios, Over/Under, BTTS, victorias, derrotas, porterías a cero y doble oportunidad.
6. Ordena los mercados por una puntuación estadística.

## Importante
La puntuación es un indicador estadístico, no una garantía de resultado ni de rentabilidad. Esta versión no consulta cuotas ni datos externos.
